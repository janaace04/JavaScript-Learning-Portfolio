# 🧠 Learning Method

Each topic will follow this process:

```text
1. Learn the concept
       ↓
2. Understand why it exists
       ↓
3. Write the code
       ↓
4. Experiment with the code
       ↓
5. Solve small exercises
       ↓
6. Understand common mistakes
       ↓
7. Apply it in a mini project
       ↓
8. Document the learning
       ↓
9. Commit to GitHub
```

The focus is on understanding and practical usage rather than memorizing syntax.
